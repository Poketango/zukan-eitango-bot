# X（@zukan_eitango）運用の方針（2026-11-14 てこ入れ）

## なぜ伸びなかったか
- 英単語・英語名の穴埋めやクイズは「勉強」に見えて、ポケモン好きが反応する理由がうすかった。
- 文章だけの投稿、ハッシュタグ2つ、本文のリンクは、いまのXのおすすめに乗りにくい。
- 投稿が週4本＋アンケート3本と少なく、話題もYouTubeの雑学チャンネルとつながっていなかった。

## 参考にしたこと（同業の雑学・ポケモン系アカウントとXの仕組み）
- 伸びる雑学投稿は「画像1枚で完結」「数字や具体名の言い切り」「見た目と中身の落差」「一言で答えられる問いで締める」。
  （例 ポケモン総数が教育漢字の数を超えた話、図鑑説明が怖い系、大きさ比較画像、シルエットクイズ）
- いまのXは、返信・引用・滞在時間・画像の中身を重く見る。フォロワーの少ない新しい投稿には、おすすめに出る枠がある。最初の30〜60分の反応が大事。
- 同じ人の連投は表示が減る。リンクは本文より自分のリプ欄に置く。ハッシュタグは0〜1個。「RTして」などの行動依頼や無差別フォローは減点。
- VOICEVOX解説系の投稿者は、動画のショート版をXに貼るより「動画を見なくても中身がわかる画像」を貼る方式に切り替えて効果を出している。

## これからの運用（2026-11-14 ユーザーの指示「もっと投稿頻度を上げて、積極的にアカウントをフォローして」を反映）
1. 毎日20:07ごろ：今日の横動画の「話題1」の雑学カード（縦長画像）を投稿し、自分のリプ欄に今日の動画のURLを置く。
2. 同じ実行で翌日の3本を予約：7:34に話題3、12:34に話題2、17:04に話題4（今日の回）。1日4本、間は4時間以上あける。話題5・6はアンケートと答え合わせ用。
   予約一覧（x.com/compose/post/unsent/scheduled）で重複がないか確かめる。
3. フォローを積極的に：毎日20〜30人（上限50）。最近1週間以内に投稿している、ポケモン（雑学・考察・図鑑・実況・ポケカ・イラスト・GO）について自分の言葉で発信する個人アカウント。業者・宣伝だけ・成人向け・政治や宗教・相互募集だけのアカウントは除く。数人ずつ間をあける。フォローしてくれたポケモン関連の人は全員フォローし返す。解除は「14日たってフォローバックなし、かつ1か月以上投稿なし」の人だけ1日10人まで。記録は x/follows.txt。Xから制限や警告が出たらその日はすぐやめて報告。
4. 交流：自分へのリプには中身に合わせて1〜2文で返す。伸びている直近のポケモン投稿5件まで、関係のある雑学を1〜2文でリプか引用（リンクなし）。フォローした人の投稿に3〜5件いいね。
5. 月・金 19時前：アンケートを「雑学クイズ」に（今日の回の話題3〜6から。答えは2日後にリプでカード画像つき）。水は「日本語名vs英語名」を続ける（サイトとのつながり）。
6. 日曜：1週間の数字を見て型を調整。英語版図鑑が怖い系を週1本（日曜朝）。プロフィールを「ポケモンの意外な雑学を毎日画像1枚で」に変え、反応のよかった投稿を固定。
- カードは台本の各話題の "x" から Actions「x-cards」が自動で作る（x_cards.py）。使ったカードは x/used.txt に記録。
