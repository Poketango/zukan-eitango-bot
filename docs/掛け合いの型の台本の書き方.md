# 掛け合いの型「英語名の意味」（talk）の台本の書き方（2026-11-16）

夜19:05の回に、talk/ の台本を若い番号から1本ずつ出す（shorts_log.jsonl に同じ題名があれば飛ばす）。台本が尽きると、その回は旧型に戻る。
残りが少なくなったら、次の決まりで書き足す。

- 題材：英語名の意味を知ると、見た目の印象とずれて二度見するポケモン（処刑、のろま、おぞましい、吐く など）。
  name_origins.json（出典つき）を手がかりに、Bulbapedia や英英辞典で裏取りする。確かめられない話は使わない。
  ポケモン好きなら誰でも知っている由来、ただの直訳、驚きのない合成語は使わない。過去の台本と同じポケモンは使わない。
- 流れ：ずんだもんが自信満々に勘違い → めたんが本当の意味（parts で単語と意味の札、big でオチの言葉を特大表示）
  → ずんだもんの驚き → もう一段の意外な話（進化後の名前、他の言語の名前、図鑑の記述、元になった実物）→ ずんだもんの一言でオチ。
  知らない固有名詞は説明する。知識の羅列にしない。5〜6行、字幕は1行60字以内。
- 字幕 t には英語を書いてよいが、読み上げ v は英字を入れずカタカナにする（英語名の読みは en_kana.json に合わせる）。
- 書き終えたら初めて見る人のつもりで読み直し、何を指すかわからない言い方を直す。字幕を直したら v も直す。
- title にはポケモンの名前を入れ、何の話かわかる言い切りにする。src に出典URLを入れる。
