# 編集の作法（全チャンネル共通）

2026-11-16 に、同系統のショート300本（スポビト80本・ハル映画50本・奇跡の瞬間50本・宇宙と科学の実話120本）を調べて決めた。
ポケモン雑学採掘所・図鑑で英単語クイズ・宇宙の衝撃ファイルのすべての動画づくりで守る。
詳しい数字は Notion「実話ナレーション型ショートの作法（300本の分析）」 https://app.notion.com/p/41ac7f671fd081bb85a9c179e9ef9378

## 1. 声と冒頭
- 声は0秒から始める（上位は0.1〜0.2秒）。無音やタイトルだけの間を作らない。
- 最初の1秒に一番強い音を置く。冒頭の衝撃音を1発鳴らす（sfx.py の impact。英単語クイズは Mix が自動で鳴らす）。
- 最初の一言は、題名をそのまま読むか、問いかけにする。場面の途中から語り出すのもよい。
- 最初の3秒は1つの絵。ショートの台本では1行目と2行目を同じ画像にする（宇宙は 2行目の shot に cont:true）。

## 2. 画面の切り替え
- 大きな切り替えは4〜5秒に1回が目安。字幕ごとには替えない。間はゆっくり寄せる動きでつなぐ。
- 横動画も、同じ図を見せている間は画面を替えない。

## 3. 効果音（sfx.py）
- 効果音は「起きた瞬間」だけに鳴らす。字幕ごとの「ポン」は鳴らさない。
- 役割で使い分ける。冒頭と答え・結末＝衝撃音、場面や画像の切り替え＝シュッ、赤丸や札が出た瞬間＝ポン、謎が解けた瞬間＝キラーン、画面いっぱいの大きな一言＝ドン。
- 数は30秒で6〜10個（横動画は30秒で6個まで）。多いときは sfx.thin がポン→シュッの順に間引く。
- 目立つ効果音は笑いどころの一発だけにする。コメント5,739件のうち効果音に触れたのは4件で、どれも笑いどころの音だった。
- 素材は OtoLogic（CC BY 4.0）。使った動画の概要欄に「効果音：OtoLogic（https://otologic.jp）」を書く（採掘所ショートと英単語クイズは自動で入る。横動画と宇宙は台本係が書く）。

## 4. BGM
- BGMは最初から最後まで切らさない。声の間は下げる。
- 答えや結末の瞬間に、曲の盛り上がりを合わせる。視聴者は「音楽でタイミングが分かる」と喜ぶ。
- 切ない話はピアノとシンセの静かな曲、謎解きは控えめなビート、と話に合わせて選ぶ。同じ曲ばかりにしない。

## 5. 台本の書き方
- 答えや結末を言う行に `"ans": true` を書く（キラーンにしたいときは `"ans": "idea"`）。答えで衝撃音が鳴る。
- 機械や人が実際に言った言葉、記録に残る一文は、そのまま字幕で見せる。視聴者の感情移入とコメントを呼ぶ。
- 終わりは、本物の音（実際の交信、歓声、ゲームの実際の音など）か、一言で答えられる問いかけで締める。まとめで要点を並べ直さない。
- 視聴者が自分の言葉で言い換えたくなる余白を残す（擬人化しやすい一言、意外な比喩）。
- 本物の記録であることを見せる。「実際の映像」の札、出典の画像、概要欄の出典。AIの映像を疑う声が多いので、本物であることがそれだけで強みになる。

## 6. 量産型と判定されないために
- 毎回、つかみの型・効果音の組み合わせ・BGM・見出しの言い回しを変える。作法は守りつつ、同じ動画の繰り返しに見せない。
