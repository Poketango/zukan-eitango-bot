# ショート動画の型の成績（図鑑で英単語クイズ）

毎週の定期作業で、投稿から48時間以上たった動画だけを使い、型（kind）ごとの再生数を比べて判断する。
決まり：1つの型に3本以上そろうまで判断しない。中央値が最下位で、ほかの型の中央値の半分に満たない型は外す（最低4つは残す）。中央値の上位2つは KINDS に2回ずつ入れる。

## 2026-11-25（1回目の判断。11/18 は利用上限で止まったので2週分まとめて）

対象：11/14〜11/23 の投稿（48時間以上たったもの）31本。全体の中央値 929回。

| 型 | 本数 | 中央値 | 平均 |
|---|---|---|---|
| rank（怖い一文ランキング） | 3 | 1,056 | 1,074 |
| scary（怖い図鑑） | 3 | 999 | 991 |
| name（英語名クイズ） | 3 | 970 | 951 |
| plus（足し算クイズ） | 2 | 937 | 937 |
| talk（英語名の意味・夜の回） | 7 | 917 | 816 |
| which（4択の図鑑） | 3 | 895 | 791 |
| real3（本物の英語名3択） | 3 | 883 | 961 |
| speed5（5連発） | 3 | 839 | 615 |

判断したこと
- 外す型：なし（最下位の speed5 でも 839回で、ほかの型の半分を大きく上回る。平均が低いのは 6回で止まった1本のため）。
- 増やす型：rank と scary を KINDS に2回ずつ入れた。
- 型の回し方を直した：夜の回が talk になると、その回に当たる型が飛ばされていた。「これまでの talk 以外の本数」で順番を回すようにし、出題の番号も投稿ごとに必ず変わるようにした（同じ型が1周に2回出ても同じ出題にならない）。
- BGM：本数3本以上で中央値が全体の半分（465回）未満のものはなかったので、外したものはなし。
- 新しい音：リードの音色「vibes」（ゆれるビブラフォン風）、リズム「disco」（裏拍のオープンハット）を music.py に追加。
- 気になる点：talk の台本は残りわずか（13本中ほぼ使い切り）。使い切ると夜の回も KINDS の順番になる。
